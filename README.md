- 🔀 Comunicación híbrida: **REST síncrono (OpenFeign)** + eventos asincrónicos **(RabbitMQ)**
- 🧪 **52 tests de integración con Testcontainers** (MongoDB real en Docker) — 99% coverage con JaCoCo
- ⚙️ Pipeline **CI/CD con GitHub Actions**: push → build → redeploy automático en VPS

- 📄 Documentación **Swagger** centralizada para todos los microservicios
